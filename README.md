# Rangilo
RANGILO ✦ Garba Nights is a responsive, HTML/CSS/JavaScript-based website built for festive celebration and music-driven engagement. The project features:  a live-style Garba playlist with YouTube music playback interactive controls for playing, pausing, skipping, shuffling, and muting tracks animated dancer visuals and celebratory festive styling a Garba “101” section explaining common dance rhythms and moves a suggestion box where users can submit favorite songs for the community playlist a mobile-friendly layout suited for event promotion and social sharing This project is ideal for Navratri, Garba events, or any culturally vibrant celebration page that wants to combine music, interactivity, and visual storytelling.
